# dotfiles

Backpack from Home to Work over the ⛰️.

## Prerequisites

Follow the order:

1. Install zsh on Linux (nothing to do on macOS)
2. Change default shell to zsh for the user - `chsh -s /bin/zsh`
3. Install [Homebrew](https://docs.brew.sh/Homebrew-on-Linux) and its dependencies
